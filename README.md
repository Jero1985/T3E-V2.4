# T3E-V2.4
T3E Home Assistant-Integration mit ESPHome. Hardware: ESP-S3 wroom1, Zigbee-Modul ZT3L, 4" BH0401-01 JXL, GT911. Hallo, ich bin ein absoluter Neuling und nutze viel KI. 
ESP-Flash über einen „USB-zu-TTL-Adapter“ und „flash_download_tool“ war kein Problem, 
Mit aktueller Yaml-Code besteht aus zwei Teilen. Einmal die Hardware.yaml und eine Haupt.yaml inkl. Testoberfläche.
Mittlerweile funktionieren WLAN, Zigbee, Relais, Display, Touchscreen und die Verbinung hin und zurück zu Home Assistant läuft auch. Ich denke ich habe es mit diesen Aliexpress Model geschafft mir ein open source Display zuerschaffen.
